# LUV ME  (v1.1.0)

1. Unzip the folder.
2. Open `js/config.js` and set names and messages (or use `index.html?to=Sam&from=Alex`).
3. Double-click `index.html` to preview.
4. To share it, upload the whole folder to Netlify Drop, GitHub Pages, or any host.

Files
- index.html: structure
- assets/: logo (tab icon + footer), favicon and app-icon PNGs
- css/style.css: look and feel
- js/config.js: your texts and names (edit this one)
- js/main.js: behavior
- js/confetti.js: heart confetti
- VERSION / CHANGELOG.md: version info
